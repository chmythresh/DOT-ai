# DOT

## Personal AI Assistant

DOT is a personal AI assistant designed to understand voice and text
commands and help with everyday digital tasks.

## Vision

DOT will be able to:

- Understand natural language
- Have conversations
- Control the laptop
- Open and manage applications
- Work with files and folders
- Browse the web
- Read and understand documents
- Understand screenshots and screen errors
- Remember useful information
- Schedule tasks and reminders
- Ask permission before sensitive actions
- Provide a professional web interface
- Support future phone integration
